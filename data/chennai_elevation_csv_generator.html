Chennai Elevation (DEM) → CSV

Pulls real elevation values (SRTM/ASTER-based) from the free, public Open-Elevation API for a grid of points over Chennai, then downloads a CSV of latitude, longitude, elevation (m).

Default box covers Chennai city + coastline.
Data source: Open-Elevation (open, no API key, no cost). Runs entirely in your browser — no data leaves your machine except requests to the elevation API itself. Larger boxes / finer spacing = more points = longer wait (public API is rate-limited).
